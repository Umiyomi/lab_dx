---

## 1. 目的

外部データ（来館者統計モック）で確認した傾向を踏まえ、来館者の**体験評価・感情・再訪意向**を探索的に把握するための調査票を設計する。

対応する研究課題:

- **RQ1:** 印象的な体験の特徴 → Q4（展示）、Q5–Q7（評価・感情）
- **RQ2:** 属性・訪問条件と体験の関連 → Q1–Q3
- **RQ3:** 体験パターンの存在 → Q6（感情）、Q2/Q3 との組み合わせで後段解析

---

## 2. 外部データから得た仮説（設計の根拠）

`data/mock/visitor_data_mock.csv` の傾向（モック）:

- クラゲゾーン・イルカショーの満足度・滞在時間が相対的に高い
- 週末来館者数は平日より多い（デート・家族利用の可能性）

→ 展示別の印象（Q4）と、訪問目的・同伴者（Q2, Q3）を必ず取る。  
→ 「ロマンチック文脈」（デート / 恋人同伴）を後から派生変数化できるよう、選択肢を分けておく。

---

## 3. 調査票の構成方針

| セクション | 目的 | 設問数 |
|-----------|------|--------|
| 基本属性 | 属性別の比較 | Q1–Q2 |
| 訪問状況 | 文脈・展示の把握 | Q3–Q4 |
| 体験評価 | 主アウトカム | Q5–Q7 |
| 再訪意向 | 行動意向 | Q8 |

所要時間の目安: 3–5分。来館直後または退館前に配布想定。

---

## 4. 設問案

### 4.1 基本属性

**Q1. 年齢区分**（単一選択）

- 10代 / 20代 / 30代 / 40代 / 50代以上  
- 理由: 細かい年齢より区分で十分。匿名性も保ちやすい。

**Q2. 本日の訪問目的**（単一選択）

- デート / 家族レジャー / 友人とのレジャー / 一人での観光 / その他  
- 理由: RQ2。デートは感情・再訪との関連を重点確認。

### 4.2 訪問状況

**Q3. 同伴者**（単一選択）

- 恋人・配偶者 / 家族 / 友人 / 一人 / その他  
- メモ: Q2 と重複気味だが、目的と実際の同伴は一致しない場合があるため両方取る。

**Q4. 最も印象に残った展示・エリア**（単一選択）

- クラゲゾーン / ペンギン館 / イルカショー / 熱帯魚トンネル / 触れ合いプール / その他  
- 理由: 外部データの人気エリアと選択肢を揃える（RQ1）。

### 4.3 体験評価

**Q5. 体験全体の評価**（5段階リッカート: 1–5）

- 1 = 非常に悪い … 5 = 非常に良い  
- 主アウトカムの一つ。

**Q6. 体験中の主な感情**（複数選択）

- ワクワク / 癒し / 感動 / ロマンチック / 驚き / 特にない  
- メモ: 複数可だが、集計時は代表感情1つに集約するルールを `data_dictionary.md` に書く。

**Q7. 感情の強さ**（5段階リッカート: 1–5）

- Q6 とセットで RQ3 のパターン探索に使う。

### 4.4 再訪意向

**Q8. 再訪意向**（単一選択）

- ぜひ行きたい / 行きたい / どちらとも言えない / 行きたくない  
- Q5, Q7 とのクロス集計を想定。

---

## 5. 設計上の決定事項

| 論点 | 決定 | 備考 |
|------|------|------|
| Q6 複数選択の扱い | モックでは `primary_emotion` として1値に集約 | 本調査では全選択を保持するか要検討 |
| 自由記述 | v1.0 では入れない | コーディング負荷を避ける |
| 展示リスト | 外部データの `popular_area` と一致 | 辞書との整合 |
| 機密データ | 個人名・連絡先は取らない | リポジトリには合成データのみ |
