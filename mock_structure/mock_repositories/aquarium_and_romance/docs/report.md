# 解析報告書（モック）

## 1. 概要

本報告書は、水族館体験アンケート（合成データ）に対する探索的解析の結果をまとめたものである。科学的結論の提示ではなく、研究ワークフローの再現性確認が目的である。

## 2. データ

- 回答数: 120件（人工生成）
- データ定義: `docs/data_dictionary.md`
- 処理後データ: `data/processed/analysis_dataset.csv`

## 3. 主要結果（要約）

### 体験評価

- 全体の平均体験評価はおおむね 3.8〜4.2 の範囲
- クラゲゾーン・イルカショーを印象展示とした回答者で評価がやや高い傾向

### 感情・文脈

- ロマンチック文脈（デート目的または恋人同伴）では「ロマンチック」「癒し」の選択が多い
- 感情強度は文脈により差が見られる

### 再訪意向

- 体験評価・感情強度が高い群で「ぜひ行きたい」「行きたい」の割合が高い

## 4. 再現方法

```bash
python scripts/run_analysis.py
```

生成物は `results/figures/` および `results/tables/` に出力される。

## 5. 限界

- すべて合成データであり、一般化可能な知見ではない
- 本リポジトリはラボ標準構成のデモンストレーション用である
